# Software Rasterizer

A software implementation of a 3D rasterization pipeline inspired by the OpenGL rendering pipeline.

Unlike OpenGL, which uses dedicated GPU hardware, this project performs the rendering process entirely on the CPU and writes the final output images to TGA files.

I created this project to deepen my understanding of computer graphics and the rasterization pipeline. Through this implementation, I explored topics such as coordinate transformations, triangle rasterization, barycentric interpolation, perspective correction, texture mapping, depth testing, and anti-aliasing.

## Features

- 3D model rasterization to 2D images
- Perspective-correct interpolation
- Vertex color interpolation
- Texture mapping
- Mipmap generation and level selection
- Texture wrapping modes
- Virtual camera system
- Face culling
- Wireframe rendering
- Multisample anti-aliasing (MSAA)
- Z-buffer depth testing

## Dependencies

The project uses the following libraries:

- **GLM**
  - Used for vector and matrix mathematics.

- **CMake**

## Installation

Clone the repository:

```bash
git clone https://github.com/YassinRamadan1/Software-Rasterizer.git
cd Software-Rasterizer
```

Build using CMake:

```bash
mkdir build
cd build

cmake ..
cmake --build .
```

After building, run the generated executable to render the scenes.
